# Authored Content is verified by an automated check, not a native speaker

We considered requiring a native Polish speaker to review every Unit before public release and decided against it for v1. Instead, every drafted sentence and verb form goes through a separate automated check against reference sources (dictionary and conjugation tables) before it ships, and the app carries a "report a mistake" action so Learners can flag what slips through.

## Consequences

- Some errors, especially unnatural phrasing that is still grammatical, may reach Learners; reports are the safety net.
- Content must be stored in a form a script can check sentence by sentence.
- Adding a native-speaker review later is purely additive and does not change the content format.
